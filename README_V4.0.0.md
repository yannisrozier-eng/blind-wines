# Blind Wine V4.0.0 — Blind Game Night

Version centrée exclusivement sur l’expérience joueur du mode Blind.

## Installation
- Si V3.9.1 est déjà installée : déployer simplement les fichiers frontend. Aucun SQL à rejouer.
- Pour une installation neuve : `supabase.sql` reste le script complet fresh-install.
- Conserver le `config.js` de production avec l’URL Supabase et la publishable key.
- Après déploiement, effectuer un rechargement forcé afin de prendre le cache `blind-wine-v400-blind-gameplay`.
