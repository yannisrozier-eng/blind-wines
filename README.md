# Blind Wine V3.9.1 — Fresh Install

Build complet basé sur V3.8.1 Fresh Install avec nouvelle expérience joueur Découverte.

## Installation Supabase
1. Ouvrir Supabase > SQL Editor.
2. Exécuter **uniquement `supabase.sql`** en entier.
3. Aucune migration V3.9.1 n'est nécessaire : le schéma SQL est identique à la V3.8.1 Fresh Install.

## Déploiement
- Conserver votre `config.js` de production avec votre URL et votre publishable key Supabase.
- Envoyer tous les autres fichiers et le dossier `js/` sur GitHub.
- Laisser Vercel redéployer.
- Faire un rechargement forcé une fois après le déploiement.

## V3.9.1
Le mode Découverte joueur ajoute : mission du verre, interactions sensorielles visuelles, micro-révélations et progression pédagogique pendant la soirée.
